### On any aria_snapshot/DOM-parsing story, run the parser first-hand AND check the "faithful" fixture actually matches shipped markup — green tests hide both (2026-07-07, 162-11)

Latent (today's Chromium emits `- log:` with no trailing space) so ALL tests were green. **Reproduce it yourself: `python -c "from ...detect import two_names_one_enemy; print(two_names_one_enemy(snap_with_trailing_space))"` → None.** Rule-checker + my repro caught it; static reading alone did not. ### "Loud but mislabeled" is a HONESTY reject, not a No-Silent-Fallbacks pass — a broad `except` that re-raises a SPECIFIC-cause error/OTEL event lies even though it doesn't swallow (119-4 review, 2026-06-16)
